# Codex Pilot 3.0

已确认范围：对话与项目检索；Fast 作为独立模型统计项；保留菜单栏并提供按需打开的双栏详情窗口；首次使用与运行状态。

## 界面

沿用原生系统字体与现有配色：纸面 #fbfbfa、正文 #262628、次要文字 #68686c、分隔 #e2e2df、选中 #f0f0ee、强调 #35745d。深色继续使用现有 PanelPalette。字号 10/11/12/14/20，数字使用等宽数字，正文保持原文并可选择复制。

菜单栏维持双行 TPS / 额度。菜单详情维持紧凑列表与参数。用户可展开独立详情窗口，左侧筛选、发起消息和折叠调用，右侧显示选中调用的证据、参数、消息与输出。窗口按需创建，关闭释放视图，不增加常驻 Dock 图标。

```
┌ 项目 / 对话 / 模型及 Fast / 关键词 ──────────────┐
│ 发起消息与调用列表       │ 选中调用：模型与 TPS    │
│ ▸ 用户消息              │ 项目 / 对话 / 来源     │
│ ▾ 用户消息              │ 六项用量参数           │
│   工具 / 输出           │ 发起消息               │
│                         │ 本次输出或工具参数     │
└─────────────────────────┴─────────────────────┘
```

以分隔线和对齐组织信息，复用原生虚拟列表；保留模型名、数值后的单位与默认折叠。筛选只针对已保留样本和本地摘要，不承诺完整历史全文搜索。

## 数据约束

- 不改变模型原始字段、数值、计时、配对或重叠拒绝规则。Fast 只由明确的 fast/priority 档位识别，用展示键独立分桶，每桶保留 100 条；未知档位不冒充确认的普通模式。
- 项目和对话名称仅取同一 conversationID 的本地 threads 元数据；冲突、缺失或旧 schema 不猜测。
- 不新增任务时间线、思考计时或复合性能分数。
- 原始采集独立于窗口开关；新增筛选不触发全量日志扫描，不增加空闲轮询。

## 验收

数值回归、Fast 隔离与保留、无证据/冲突元数据、筛选与折叠完整性、窗口生命周期、中英文浅深色、首次使用各状态。完整包构建后使用隔离演示数据检查界面；正式替换与发布需在结果可审阅后进行。12 小时能耗观察单独记录，不能用短时测试冒充。
