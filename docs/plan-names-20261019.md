# Pro 套餐名称核查 · 2026-10-19

适用版本：Codex Pilot 2.8.3 / build 39。

## 结论与来源

无需新增订阅查询。现有 `plan_type` 有不同的规范标识；官方客户端已把旧标识映射为编号名称，我们的显示映射落后了。

| 服务端规范标识 | 显示名称 |
| --- | --- |
| `prolite` | Pro 100 |
| `pro` | Pro 200 |
| `promax` | Pro 500 |

核查本机官方客户端 26.1013.40934 / build 20770 的只读资源：

- `webview/assets/status-b27bb03d5057.js`：账单设置的 `settings.consumerBilling.planName.numberedTiers` 明确列出以上映射；说明该值是持久化的账号套餐类型，名称不取决于当前可购买的档位；实际取值来自 `account.plan_type`。
- `webview/assets/plan-names-666e9b8a18cd.js`：订阅与升级名称使用相同映射。
- `webview/assets/app-initial-90eb42395b7d.js`：套餐枚举同时包含 `prolite`、`pro`、`promax`。

[OpenAI 官方套餐文档](https://learn.chatgpt.com/docs/pricing)也列出 100、200、500 美元/月三个 Pro 档位。准确的标识映射依据是上述官方客户端资源，不是从价格、额度、速度模式或购买选项推断。

本次只读实查：当前账号的 `/backend-api/wham/usage` 与官方客户端使用的 `/backend-api/wham/accounts/check` 均返回 HTTP 200、套餐 `pro`；后者按账号 ID 精确匹配，没有借用其他账号。当前账号因此显示 Pro 200。100/500 档位来自官方映射与模拟响应回归，未声称有这两个档位的实付账号可供现场验证。
